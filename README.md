# Biological Sequence Analysis Using Python

A computational biology project designed to analyze DNA nucleotide sequences, compute core genomic metrics (GC content, base composition), locate specific sequence motifs (restriction sites), and visualize regional GC variation using Python.

## Project Overview
This project bridges pharmaceutical science and data analysis. It computes critical physical-chemical properties of genomic sequences (such as GC ratio affecting DNA melting temperatures) and identifies functional motifs.

## Features
- **Nucleotide Composition Analysis:** Measures distribution of A, T, C, and G bases.
- **GC Content Calculation:** Computes overall GC percentage for DNA stability profiling.
- **Motif & Restriction Site Detection:** Locates target enzyme recognition sequences (e.g., EcoRI `GAATTC`).
- **Genomic Visualization:** Generates sliding-window GC plots using `matplotlib`.

## Technologies Used
- **Language:** Python
- **Libraries:** `matplotlib`, `re`
